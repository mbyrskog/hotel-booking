Welcome to MB Hotels

Use this portal to manage guest reservations. You can create a new reservation, view all upcoming stays, and edit or cancel a booking in a few clicks.

  • Create a new reservation: enter the guest's details, room number and dates.
  • View all reservations: see every booking, then edit or delete it.

Reservations are saved in this browser only. They aren't shared with other devices, and clearing your browser data removes them.
